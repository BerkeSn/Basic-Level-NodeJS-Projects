# 🛠️ Handcrafted Labs

A curated collection of small, focused programming projects and utilities written completely by hand—**strictly without the assistance of AI code generators or copilot tools**.

---

## 🎯 The Philosophy

The sole purpose of this repository is **deliberate practice and genuine problem-solving**. 

In an era where code generation is instantaneous, this space is dedicated to:
- Struggling through problems and learning from runtime errors manually
- Developing raw coding reflexes and deep syntax fluency
- Reading official documentation and API references directly
- Strengthening foundational computer science and software engineering fundamentals

Every folder in this repository represents an isolated concept, tool, or mini-project built from a blank slate.

---

## 📌 Rules of this Repo

1. **No AI assistance:** Zero LLMs, ChatGPT, Copilot, or automated code generation.
2. **First principles:** Prioritize understanding *how* and *why* every line works.
3. **Vanilla & native first:** Maximize usage of built-in APIs before reaching for third-party libraries.
