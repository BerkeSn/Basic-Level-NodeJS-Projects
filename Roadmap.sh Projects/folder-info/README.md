# Directory Content Counter (Node.js)

Bu proje, Node.js dahili `fs` ve `path` modüllerini kullanarak belirtilen bir klasörün (veya mevcut dizinin) içindeki toplam dosya ve alt klasör sayılarını analiz eden komut satırı (CLI) aracıdır.

---

## 🚀 Gereksinimler

- **Node.js**: v18.0.0 veya daha yeni bir sürüm (Top-level await desteği için v18+ önerilir).

---

## 🛠️ Kurulum

Herhangi bir harici paket (`npm install`) kurulumuna gerek yoktur. Node.js'in yerleşik modülleri (`node:fs/promises`, `node:path`) kullanılmıştır.

Proje dosyalarını yerel makinenize indirin veya klonlayın:

```bash
git clone <repository-url>
cd <project-folder>
